# 기존 아카이브 가져오기

처음부터 다시 받을 필요가 없습니다. Channel Vault NAS는 오래된
`youtube-dl` / `yt-dlp` 사용자가 이미 갖고 있는 두 가지를 대조할 수 있습니다.

- NAS 폴더의 영상과 사이드카 파일
- `--download-archive` 텍스트 파일

자동 백업을 시작하기 **전에** 기존 영상을 보관 완료로 표시해서, 같은 영상을 다시
받지 않는 것이 목표입니다.

## 1. 기존 폴더 마운트

`CVN_DOWNLOAD_HOST_DIR`를 기존 아카이브가 있는 폴더로 지정합니다.

```env
CVN_DOWNLOAD_HOST_DIR=/volume1/video/channel-vault
```

Compose를 시작하거나 재시작합니다. Channel Vault는 스캔 중 기존 파일의 이름을
바꾸거나 삭제하지 않습니다.

## 2. NAS 폴더 스캔

**채널 → 가져오기 키트 → 기존 NAS 폴더**를 열고 스캔을 미리 본 뒤 적용합니다.
디스크의 영상, 썸네일, 자막, `info.json` 사이드카가 색인됩니다.

!!! tip "사이드카는 영상 옆에 두세요"
    `video.info.json`이 있으면 가장 정확하게 연결됩니다. 없어도 복구할 수 있지만
    제목만으로 맞추는 경우 정확도가 낮아질 수 있습니다.

## 3. archive.txt 가져오기

**채널 → 가져오기 키트 → archive.txt**를 열고 내용을 붙여넣거나 파일을 선택한 뒤
대조 결과를 미리 봅니다. 적용 전에 인식됨, 중복, 잘못된 행을 확인하세요.

다음과 같은 일반 형식을 인식합니다.

```text
youtube VIDEO_ID
VIDEO_ID
https://www.youtube.com/watch?v=VIDEO_ID
```

## 4. 다운로드 전 확인

채널 화면에서 **다운받음** 수가 늘었고, **남은 영상**에 정말 없는 영상만
표시되는지 확인합니다. 다운로드 간격과 한 번에 받을 개수를 고른 다음 **자동 백업
시작**을 누릅니다.

이미 받은 영상은 이후 모든 실행에서 건너뜁니다. 데이터베이스를 잃어도 백업에서
복원하거나 파일시스템을 다시 스캔할 수 있으며, 미디어 파일은 영구 아카이브로
남습니다.
